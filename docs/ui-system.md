# 广厦有备 · 绘本设计系统

本版以森林村落、纸质手账、应急物资柜为三个交互场景。八个业务栏目与 Python 计算、MCP、SQLite 账户共用现有接口。旅程节点用于跳转，不用虚构的进度动画冒充后端实时执行。

## Token

Primary #91AC9E；Accent #E98173；Surface #F8F4EA（主纸面）/#F1E7D5（米白衬底）；Outline #B4A79A；Sky #91B8D9；Lavender #B4A2C3；Mint #BBD8CB；Yellow #E6CA78。暖灰正文 #514B47 提高文字对比，次文字 #746F68。主色按钮珊瑚底搭深灰文字，避免浅底白字不清晰。

按钮高度48px、圆角12px；主容器32px；面板24px；1px暖灰描边；8px间距网格；无重投影。标题使用本地自托管霞鹜文楷500，英文/数字Nunito，正文优先系统清晰中文字体。字体随包提供，无需Google Fonts连接，许可附在docs/font-licenses。

## 页面与状态

首页以插画引入，旅程节点跳转到数据/建筑/人员/权益。概率图在后端未返回前保持空态，不展示虚构的数值。参考模式的建筑与金额为空，旅程保留待补证标识。

数据页保留处理前后明细、观测/插值/缺失、周统计；规则页保留查询、手动触发与事件。参数变更清除旧结果，避免展示过期情景。物资柜选择物品后才可兑换，额度/库存/年度关闭均由后端校验，成功后更新余额与流水；冲正按原记录执行。不存在真实购买与配送。

手机端保留可横向滚动的八栏目导航，并提供四项快捷底栏；桌面使用完整章节导航。小屏表格在表格容器内滚动。交互有键盘焦点、ARIA选择状态、错误/完成播报，尊重prefers-reduced-motion。

## 视觉概念与实现约束

概念里的村落、伙伴、纸面、路径、八栏目与双列信息结构作为实现依据。概念中的示例柱图改为真正的后端结果或空态；额外木牌文字省略，所有说明留给HTML。顶部标志使用原生房屋与叶子线描图标，避免在小尺寸缩放插画文字。绘本风格不改变模型真实性边界。
